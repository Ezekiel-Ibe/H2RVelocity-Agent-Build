# Visual Reference

The initial visual baseline is the uploaded **Design 1** workspace image.

## Desktop layout

- **Primary navigation (left):** KPMG mark; Home, Engagements, Payroll Data,
  Assurance Checks, Exceptions, Reports, Insights, Agent, Settings; user footer
  (avatar, name, email); copyright; Privacy | Legal links.
- **Page header:** product title, descriptive subtitle, "KPMG. Make the Difference."
- **Welcome banner:** greeting with decorative gradient wave.
- **Key metrics:** Payrolls Processed, Employees Covered, Exceptions Identified,
  Assurance Score — each with value, caption, and trend.
- **Assurance Overview:** donut score with High/Medium/Low risk breakdown and total.
- **Recent Exceptions:** severity-badged list with affected counts.
- **Active Engagements:** table of engagement, client, period, status, score, updated.
- **Agent workspace (right):** agent identity, AI status badge, welcome message,
  suggested prompts, conversation, composer, and AI accuracy notice.

## Provenance note

Names, engagement details, metric values, and exception values shown in the image
are reproduced only as **clearly labelled synthetic development fixtures**
(`src/fixtures/`). They are not production data.
